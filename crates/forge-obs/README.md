`forge-obs` is Yantra's observability substrate. Every LLM call, tool call, and orchestrator decision is recorded as an OpenTelemetry `Span` and persisted in `.yantra/traces.sqlite` (WAL mode) via `record_span`. The cost gauge reads the per-session `SUM(cost_usd)` from the traces database and classifies it as Ok/Warn/Pause/Kill against the three thresholds from `configs/routing.toml` (`soft_usd`, `hard_usd`, `kill_usd`). The anomaly detector flags spans whose cost or duration exceeds 3× the rolling session median. The watchdog binary sends a heartbeat every 30 seconds and snapshots orchestrator state if the heartbeat goes silent for 5 minutes. Decision archaeology records are also stored here, forming the causal chain that the Time-Travel Debugger (`yantra ttd`) replays. The `yantra observe` live TUI reads all of this in real time via a ratatui interface.
