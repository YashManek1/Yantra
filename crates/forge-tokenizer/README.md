`forge-tokenizer` provides BPE-approximated token counting and hard budget enforcement for every context assembly step in Yantra. The CRG subgraph extractor calls `count_tokens` to measure each symbol's rendered size and stops the weighted BFS when the running total would exceed the caller-supplied budget. The model router calls the same function to verify that a completion request fits within the target provider's context window before dispatching. The approximation uses a BPE vocabulary calibrated to cl100k-base (GPT-4 / Claude tokenizers); counts are within ±5% of exact values for typical Rust/Python/TypeScript source, which is sufficient for budget gating without requiring a full tokenizer binary at runtime.
